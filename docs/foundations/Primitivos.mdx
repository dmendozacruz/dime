# Primitivos

La paleta base de DIME: los valores en bruto de los que salen los tokens semánticos. En Figma están en la colección *Globals*.

**No los uses directamente en componentes ni en la web.** Usa el token semántico que describe el uso (por ejemplo, `--color-content-default` en lugar de `--color-neutral-900`). Así, si un primitivo cambia, todo lo que depende de él cambia a la vez. Consulta esta página para entender de dónde sale cada token, no para elegir un color.

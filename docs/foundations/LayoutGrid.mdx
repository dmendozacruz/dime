# Layout y grid

El grid ordena el contenido en columnas para que márgenes, textos e imágenes se alineen igual en todas las páginas. DIME tiene **cuatro estilos de grid**, uno por tramo de ancho más el del header.

## Tramos de ancho

El diseño cambia en tres tramos de ancho, y cada ancho pertenece a uno solo: 768 px todavía es mobile, 769 px ya es tablet, 1024 px todavía es tablet y 1025 px ya es desktop.

- **Mobile**, hasta 768 px: 4 columnas. Header de 78 px con menú de hamburguesa. Se diseña a 390 px y se revisa también a 360 px, el ancho real más estrecho.
- **Tablet**, de 769 a 1024 px: 8 columnas. Header igual que el de mobile. Se diseña a 769 px a propósito: es el primer ancho del tramo y donde antes rompe el diseño.
- **Desktop**, desde 1025 px: 12 columnas. Header de 70 px con la navegación completa. Se diseña a 1440 px, el ancho máximo: por encima, el diseño se centra y solo crece el espacio a los lados.

## Estilos de grid

Cada muestra dibuja el margen, el gutter y las columnas a escala sobre su ancho de diseño. En Figma el margen y el gutter están ligados a variables `space/*`, así que cambian con ellas; en código son los mismos tokens de [espaciado](?path=/docs/foundations-espacio-y-layout--docs). En diseño se aplica el estilo al frame, nunca columnas a mano.

## En código

```css
.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  column-gap: var(--space-4); /* 16px */
  padding-inline: var(--space-6); /* 24px */
}

@media (min-width: 769px) {
  .container {
    grid-template-columns: repeat(8, 1fr);
    padding-inline: var(--space-7); /* 32px */
  }
}

@media (min-width: 1025px) {
  .container {
    grid-template-columns: repeat(12, 1fr);
    column-gap: var(--space-6); /* 24px */
    padding-inline: var(--space-13); /* 120px */
    max-width: 90rem; /* 1440px */
    margin-inline: auto;
  }
}
```

Los elementos se colocan por columnas (`grid-column: span 5`), nunca con anchos en px sueltos. Un bloque de 5 columnas en desktop mide el 40,5 % del contenido.

## Accesibilidad

- **Reflow (1.4.10).** El contenido tiene que caber a 320 px de ancho (un 1280 px con zoom al 400 %) sin scroll horizontal. Por eso mobile se revisa a 360 px y ningún bloque depende de un ancho fijo.
- **Zoom del texto (1.4.4).** Con el texto al 200 % nada se recorta: los contenedores crecen en alto. No fijes alturas en bloques con texto.
- **Orden al apilar (1.3.2 y 2.4.3).** Cuando las columnas se apilan en tablet y mobile, el orden visual tiene que ser el mismo que el del código, para que el lector de pantalla y el tabulador sigan el orden que se ve.

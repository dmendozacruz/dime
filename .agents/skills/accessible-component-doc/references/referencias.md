# Referencias visuales y de comportamiento

Dónde mirar antes de diseñar o documentar algo. **No son fuentes de verdad** (esas están en
el mapa del sistema, apartado *Fuentes de verdad*): son referencias de apoyo. Antes de
inventar una composición, un patrón o un comportamiento, mirar cómo lo resuelve alguna de
estas y contrastarlo con Figma y con la accesibilidad.

## Composición y aspecto de Storybook

- **Design system de Nueva York** (<https://designsystem.ny.gov>): la referencia principal
  (D-010). Estructura de las páginas, orden de las secciones, cabeceras de los componentes,
  ejemplos por grupos, componentes que reúnen otros (UNav Header y UNav Footer). Ver también
  `docs/storybook-guidelines.md`.
- **Carbon** (<https://carbondesignsystem.com>): las pestañas de un componente como páginas
  propias, con su dirección y una barra de navegación arriba (D-014).
- **Bella** (<https://emcdanie.github.io/bella/>): la estructura de la portada y de la
  gobernanza de un Storybook (Introducción, Identidad, Primeros pasos, Gobernanza, Changelog)
  y el README del repositorio.

## Comportamiento y accesibilidad de un componente concreto

- **Back to top.** Nielsen Norman Group (<https://www.nngroup.com/articles/back-to-top/>):
  cuándo usarlo y que en móvil aparezca solo al subir. Fundación ONCE
  (<https://www.fundaciononce.es/gl>): un botón flotante accesible, de referencia para
  contraste, tamaño y foco. Ramon Riera (<https://www.ramonriera.design>): la animación de
  entrada.

## Elementos nativos

- **MDN Web Docs** (<https://developer.mozilla.org>) y el **estándar HTML**
  (<https://html.spec.whatwg.org>): cómo se comporta cada elemento nativo, para no reescribir
  con JavaScript lo que el navegador ya hace.

Cuando se añada una referencia nueva, se apunta aquí con una línea de para qué sirve.

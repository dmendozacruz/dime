## Aviso que aparece

La región del mensaje (`.dime-alert-region`) está en la página desde que carga, **vacía**, con su rol: `role="alert"` si hay que dejar lo que se está haciendo para leerlo, `role="status"` si puede esperar. Va dentro de `<dime-alert-region>`. Al ocurrir algo, su método `show(opciones)` escribe el aviso dentro y el lector de pantalla lo anuncia. El foco no se mueve.

<Canvas of={Stories.Live} />

```html
<dime-alert-region>
  <div class="dime-alert-region" role="status"></div>
</dime-alert-region>
```

```js
import "./alert.js"; // registra <dime-alert-region>

document.querySelector("dime-alert-region").show({
  type: "success",
  title: "Done",
  content: "The action finished correctly.",
});
```

Un aviso que está desde que carga la página no lleva rol: se escribe directamente en el HTML.

## JavaScript

Es un **web component en light DOM** (D-017): `<dime-alert-region>` se registra al cargar `components/alert/alert.js` y tiene `show({ type, title, content, showContent })` y `clear()`. `show` vacía la región y escribe el aviso 100 ms después, para que se anuncie aunque el texto sea el mismo que la vez anterior.

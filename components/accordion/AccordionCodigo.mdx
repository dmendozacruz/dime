## JavaScript

Es un **web component en light DOM** (D-017): `<dime-accordion>` envuelve la lista y se activa solo al cargar `components/accordion/accordion.js`. Cambia `aria-expanded` al pulsar y pone `inert` al panel cerrado. La apertura se anima con CSS (250 ms) y se queda quieta con "reducir movimiento".

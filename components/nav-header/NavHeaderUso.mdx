## Cuándo usarlo

**Úsalo cuando**

- Tienes varias secciones o páginas a las que llegar desde cualquier punto.
- Quieres que el contacto principal esté siempre a mano.

**No lo uses cuando**

- Cambias entre paneles de un mismo contenido: usa Tabs.
- Hay una sola página sin secciones: no hace falta navegación.

## Recomendaciones de uso

- Los enlaces de navegación son pocos y cortos (cuatro caben bien).
- El logo lleva siempre al inicio.
- La página actual se marca con el subrayado y el peso, y también en el código (`aria-current`).
- Antes de la cabecera va el Skip nav, para saltarla con el teclado.
- Si la cabecera es fija, deja espacio arriba en el contenido (`scroll-padding-top`) para que no tape lo enfocado.

## Cuándo usarlo

**Úsalo cuando**

- Pides la contraseña de un contenido protegido.

**No lo uses cuando**

- Para otro tipo de dato (correo, búsqueda): hoy no existe y sería un componente nuevo.

## Recomendaciones de uso

- Etiqueta siempre visible encima del campo; el placeholder es solo un ejemplo y desaparece al escribir.
- Texto de ayuda (Show description): explica qué hay que escribir y se ve siempre bajo el campo. Úsalo solo si hace falta.
- Mensaje de error: dice qué pasa y cómo arreglarlo ("Incorrect password.", "Please enter a password."). Aparece en el mismo sitio, bajo el campo.
- El error aparece al enviar, no mientras se escribe.
- El campo ocupa el ancho de su contenedor.

## Enviar con error

El error aparece al enviar. `setError(mensaje)` marca el campo con `aria-invalid` y escribe el mensaje en `.dime-input__error`, que existe siempre (vacío) con `role="alert"`. El foco se queda en el campo. Pulsa Access con el campo vacío.

<Canvas of={Stories.Submit} />

```html
<dime-input>
  <div class="dime-input">…</div>
</dime-input>
```

```js
import "./input.js"; // registra <dime-input>

const field = document.querySelector("dime-input");
form.addEventListener("submit", (e) => {
  e.preventDefault();
  field.setError(input.value ? "Incorrect password." : "Please enter a password.");
});
```

## JavaScript

Es un **web component en light DOM** (D-017): `<dime-input>` envuelve el campo, que ya está en el HTML, y se registra al cargar `components/input/input.js`.

- Botón ver / ocultar: el botón cambia el campo entre `password` y `text`, su nombre entre "Show password" y "Hide password" y su icono.
- `setError(mensaje)`: marca o desmarca `aria-invalid` y escribe el mensaje 100 ms después de vaciar el nodo, para que se anuncie también si se repite.

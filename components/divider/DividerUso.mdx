## Cuándo usarlo

**Úsalo cuando**

- Separa dos bloques distintos dentro de una misma zona, como un contenido y su pie.
- Marca el límite entre filas que se repiten, como las de un acordeón.

**No lo uses cuando**

- Solo quieres separar con aire: usa el espaciado (`space/*`).
- Los elementos de una lista corta ya se distinguen sin línea.
- Como subrayado de un título o de un enlace: el subrayado del Link es otra cosa.

## Recomendaciones de uso

- Ocupa siempre el ancho de su contenedor; no lo recortes a mano.
- No cambies el grosor ni el color: sobre fondo oscuro (`background/brand`) usa Inverted.
- Deja el mismo espacio arriba y abajo, siempre con variables `space/*`.
- Uno entre bloques, no uno detrás de cada elemento.

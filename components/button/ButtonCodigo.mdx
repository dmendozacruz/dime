# Button

HTML y CSS, sin JavaScript. El CSS está en `components/button/button.css` y solo usa tokens de DIME. Los iconos son los SVG del set Icons, en línea para que tomen el color del texto.

### Como enlace

<Canvas of={Stories.AsLink} sourceState="shown" />

### Disabled

`aria-disabled="true"` en vez de `disabled`: así sigue recibiendo el foco y se anuncia como no disponible. Quien escriba el JavaScript de la acción tiene que ignorar el clic mientras tenga ese atributo. Si es un enlace, además, sin `href`.

<Canvas of={Stories.Disabled} sourceState="shown" />

### icon button

Solo icono, con el nombre en `aria-label`. Medium (44 px) y large (52 px).

<Canvas of={Stories.IconButton} sourceState="shown" />

Para invitar a bajar a la siguiente sección, añade `dime-icon-button--bounce`: la flecha rebota tres veces y se queda quieta. Con «reducir movimiento» activado no rebota.

<Canvas of={Stories.IconButtonLarge} sourceState="shown" />

<Canvas of={Stories.IconButtonInverted} sourceState="shown" />

### Button back

Es un enlace. El nombre accesible va en `aria-label` y es fijo; el texto que aparece al pasar el ratón es decorativo (`aria-hidden`).

## JavaScript

No necesita. El cambio de fondo en Hover y el texto del Button back se animan con CSS y se quedan quietos con "reducir movimiento".

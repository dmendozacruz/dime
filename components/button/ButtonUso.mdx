## Cuándo usarlo

**Úsalo cuando**

- Hay una acción o un destino principal que debe destacar, como descargar un documento o escribir para contactar.
- Hace falta volver a la página anterior: Button back.
- Invitas a bajar a la siguiente sección: icon button.

**No lo uses cuando**

- El destino está dentro de un texto corrido: usa un Link.
- Hay varias acciones del mismo peso juntas: destaca solo una y deja el resto como Link.
- La acción no está disponible y nunca lo estará: no muestres el botón.

## Recomendaciones de uso

- Texto corto que diga qué pasa al pulsar: "Download resume", "Let’s talk". Siempre en una sola línea: si baja a dos, hay que acortarlo.
- Un solo botón principal por zona de la página.
- Usa Inverted sobre fondos oscuros, nunca sobre fondo claro.
- Width large solo cuando el botón deba ocupar todo el ancho, por ejemplo en pantallas estrechas.
- La flecha acompaña el texto; no la uses para decir algo distinto.
- Disabled solo cuando la acción o el destino no estén disponibles, con el motivo visible cerca.

## Button o Link

Se parecen, pero no hacen lo mismo. **Decide por lo que hace, no por cómo se ve**: si al pulsarlo cambia la URL, se descarga algo o se abre el correo, es un enlace aunque tenga forma de botón. El Button back, por ejemplo, es un enlace.

## Responsive

El botón no cambia de tamaño entre breakpoints. Lo que cambia es su ancho: en pantallas estrechas, el botón principal de una zona puede ocupar todo el ancho (Width large).

## Cuándo usarlo

**Úsalo cuando**

- Hay varias vistas del mismo nivel y solo debe verse una.
- La persona necesita saltar entre ellas sin hacer scroll.
- El contenido de cada vista ya está en la página y se muestra al instante.

**No lo uses cuando**

- El destino es otra página o un ancla: usa un Link o la navegación.
- Hay una sola vista: no hace falta el patrón.

## Recomendaciones de uso

- Etiquetas cortas y distintas entre sí.
- Una sola pestaña seleccionada a la vez.
- El panel es contenido de la página: el componente es solo la barra y las pestañas.
- En mobile, centra la barra si encaja; si las pestañas no caben en una fila, replantea la estructura del contenido.
- No uses Tabs para pasos de un proceso ordenado si el avance es secuencial obligatorio.

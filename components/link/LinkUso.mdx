## Overview

Las combinaciones de las propiedades de Figma: Size small y large, flecha a la derecha o a la izquierda e Inverted sobre fondo oscuro. El texto va siempre: el enlace nunca se usa solo con el icono.

## Estados

Size small · Default, Hover, Active, Focus y Disabled. Hover, Active y Focus muestran el subrayado; Active y Focus, además, el texto en medium.

## Cuándo usarlo

**Úsalo cuando**

- Lleva a otra página, como "Open case study".
- Lleva a un perfil externo, como "LinkedIn".
- Abre el correo (`mailto:`), como "Send email".

**No lo uses cuando**

- Ejecuta una acción en la propia página (enviar, abrir, cerrar): usa un Button.
- Es la acción principal de la zona: usa un Button, que pesa más.
- Vuelve atrás o baja a la siguiente sección: usa Button back o icon button.

## Recomendaciones de uso

- Texto corto que diga adónde lleva: "Open case study", "LinkedIn". Nunca "Click here" ni "Más".
- Si hay varios enlaces con el mismo texto, el nombre accesible empieza por ese texto y añade el destino: "Open case study: Shori".
- Si abre en pestaña nueva, dilo en el nombre accesible: "LinkedIn (opens in a new tab)".
- La flecha ↗ es el icono de los enlaces a otra página, interna o externa. Las flechas ←, → y ↓ son de los botones de navegación.
- Usa Inverted sobre fondos oscuros, nunca sobre fondo claro.
- Disabled solo si el destino no está disponible (un enlace roto), con el motivo visible cerca.

## Link o Button

Se parecen, pero no hacen lo mismo. **Decide por lo que hace, no por cómo se ve**: si al pulsarlo cambia la URL, se descarga algo o se abre el correo, es un enlace aunque tenga forma de botón.

### Disabled

Destino no disponible. **No lleva `href`**: lleva `role="link"`, `aria-disabled="true"` y `tabindex="0"`, para que siga recibiendo el foco, se anuncie como no disponible y se pueda descubrir el motivo, escrito al lado.

## JavaScript

No necesita. El enlace, el teclado y los estados son del navegador. El subrayado se anima con CSS (250 ms) y se queda quieto con "reducir movimiento".

## En la página

Pulsa Tab dentro del ejemplo: aparece el enlace; con Enter, el foco pasa al contenido principal.

<Canvas of={Stories.Keyboard} sourceState="shown" />

```html
<body>
  <a class="dime-skip-nav" href="#main-content">Skip to main content</a>
  <header>…</header>
  <main id="main-content" tabindex="-1">…</main>
</body>
```

## Responsive

- **Tablet y mobile (hasta 1024 px, `@media (max-width: 64rem)`):** pasa a Size large (48 px, texto de 18 px).
- **Desktop:** Size small (40 px).
- `.dime-skip-nav--large` fuerza large en cualquier ancho. La posición y el texto no cambian.

## JavaScript

No necesita. El destino lleva `tabindex="-1"` para que el navegador le pase el foco al seguir el enlace.

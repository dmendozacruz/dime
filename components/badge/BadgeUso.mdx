## Cuándo usarlo

**Úsalo cuando**

- Necesitas una etiqueta estática, que no hace nada al pulsarla, para clasificar un contenido con una o dos palabras, como el tipo de proyecto: B2B, B2C, SaaS.
- Quieres que la categoría se vea de un vistazo junto al título.

**No lo uses cuando**

- El texto es una frase: usa texto normal.
- Comunica un estado o un aviso (error, éxito): usa un Alert.

## Recomendaciones de uso

- Una o dos palabras. Si es una sigla, el nombre completo tiene que llegar al lector de pantalla.
- Escribe el texto normal: las mayúsculas las pone el estilo.
- Varios juntos, en fila y separados con `space/2`; si no caben, bajan de línea enteros, sin cortarse.
- No cambies el color del borde ni el radio.
